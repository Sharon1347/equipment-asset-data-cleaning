# Equipment Asset Data Cleaning — Python & pandas

Python data-cleaning project for messy equipment asset records containing duplicates, missing values, inconsistent capitalization, mixed date formats and incomplete fields.

## What it does

- Removes duplicate rows
- Standardizes capitalization
- Normalizes date formats
- Handles missing values
- Maps condition codes to descriptive labels
- Exports cleaned structured output
- Generates a cleaning report

## Tools used

- Python
- pandas
- openpyxl

## Files

- `clean_assets.py` — cleaning script
- `raw_sample.csv` — raw sample dataset
- `cleaned_output.csv` — cleaned structured dataset
- `cleaning_report.txt` — summary of transformations

## Why this project matters

This project demonstrates practical data cleaning, structured validation workflows and QA-oriented dataset preparation using Python and pandas.
